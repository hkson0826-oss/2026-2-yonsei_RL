### 2. 정류장 범위와 공간 근거

공식 OA-15067의 2026-09-02 위치 목록에서 ARS `13`인 464개는 유일한 정류장 ID·ARS를 가진다. 별도 공식 시내버스 구역 표로 `13`과 서대문구의 대응을 확인했다. 이는 **공식 ARS 구역 코드 기준의 시점 고정 참조 목록**이며 모든 좌표의 행정경계 포함이나 실시간 운행 상태를 보증하지 않는다.

현재 자료에서 기존 282개는 모두 이 참조 목록에 포함되고, 원본 연구 지역 808개와 교집합은 292개다. 따라서 기존 282개가 공식 참조 목록 전체였다는 주장은 기각한다. 기준 목록으로부터 빠진 182개와 원본에도 없는 172개를 구분했다. 위도 범위와 실제 누락 목록은 북쪽 범위 부족이라는 해석을 뒷받침한다.

중앙차로는 전체 464개 중 42개다. 이를 제외한 422개는 정차 후보에 관한 정책 집합이며 모집단 전체와 다르다. 연구 가정을 실제 법적 정차 금지로 표현하지 않은 점은 적절하다.

거점 기준점은 공식 철도 역사 19개와 연대앞 버스 기준점 3개, 16개 그룹이다. 같은 역의 여러 호선과 신촌의 서로 다른 역을 구별했다. 역사 기준점·버스 정류장 기준점은 출입구·캠퍼스 정문 측량점과 다르다는 한계를 유지해야 한다.

### 3. 수요 재집계와 결측

공식 5–10월 재집계에는 2,784개 정류장–월 행이 있다. 매월 454개는 원천 기록이 있고 다음 10개는 모든 월에서 원천 행이 없다.

```text
101000248, 112000170, 112000372, 112000373, 112000374,
112000375, 112000376, 112000377, 112000440, 113000532
```

이 10개 수요는 미관측이다. 표의 빈 수치를 0으로 바꾸지 않고, 수요 준비 상태를 따로 전달해야 한다. 실제 관측 하차량이 0인 정류장과 동일하게 취급하지 않는다. 기록 부재만으로 신설·폐지·저수요·운영 중단 원인을 확정할 수 없다.

기존 282개에서 평균 정의의 최대 절대 차이는 약 0.679명/일이며 상위 10개는 같다. 최대값·min-max 차이 역시 작았다. 정의 통일의 필요성을 노선 결과의 큰 변화가 입증됐다는 주장으로 확대하지 않은 점은 적절하다.

### 4. 도로거리의 제한

원본은 공식 참조 목록과 겹치는 292개 내부에서 84,972개 방향별 비대각 거리를 제공한다. 전체 464개에는 214,832개가 필요하므로 129,860개가 없다. 전체 OSM 거리 확보가 안 된 현재 상태에서는 **464개 인덱스에 원본 값을 넣고 나머지를 `null`로 둔 부분 행렬**과 별도의 292개 완전 부분 행렬을 제공하는 안을 허용한다.

이를 전체 도로거리 준비 완료나 전체 노선 실험 준비 완료로 표현하지 않는다. 292개 완전 부분 행렬은 기존 도로자료의 진단·호환성 인계용이며, 최신 전체 정류장 확대 요구를 달성한 최종 실험 후보라고 바꾸어 부르지 않는다.

0m 비대각 값은 원본과 스냅 원인을 보존한다. 직선거리로 바꾸거나 `null`을 임의의 유한값으로 채우지 않는다. 실제 보행·회전·유턴·버스 진입 가능성은 별도 미검증 상태를 유지한다.

### 설계 진행을 막는 결함과 허용되는 범위 제한의 구별

**현재 조사에서 E 진행을 막을 결함은 발견하지 않았다.** 다음은 이미 드러난 자료 한계이며 숨기지 않는 조건으로 설계·지도 제작을 진행할 수 있다.

- ARS 코드의 시점 고정 목록이며 행정경계 폴리곤 또는 실시간 전체 운영 목록은 아님
- 수요 원천 행이 없는 10개 존재
- 전체 참조 집합의 도로거리 129,860쌍 미확보
- 역 출입구·실제 보행경로·버스 회전·정차 적법성 미검증

반대로 미관측 수요를 0으로 바꾸거나, 누락 도로거리를 0/직선거리로 채우거나, 부분 집합을 전체라고 표현하면 설계·최종 단계에서 반려한다.

### E가 지켜야 할 인계 기본 방향

1. 참조 지도는 ARS13 464개 전체를 유지한다. 수요·후보정책·도로자료 준비 여부는 서로 다른 플래그로 제공한다.
2. 수요는 학습 5–8월 합계를 123일로 나눈 기간 일평균을 기본안으로 채택할 수 있다. 목적은 날짜별 동일 가중이며 최적 수요 예측식이라는 의미가 아니다.
3. 정규화 분모는 관측된 학습 모집단 454개 전체에서 정해 고정한다. 중앙차로·부분 도로자료 등의 필터마다 척도를 다시 바꾸지 않는다. 정규화에서 빠진 결측 10개는 `null`이다.
4. 거점 기본 반경 300m, 200/500m의 공간 매핑 차이 확인, 최근접 단일 그룹 귀속은 명세 가능한 보수적 안이다. 모두 서울 최적값이나 실제 도보거리 검증값이 아니라 프로젝트 공간 근사로 표시한다.
5. `bonus=0.5`, `cost=0.2/km`와 같은 인계 기본값은 정책 선호이며 최적화 결과가 아니다. 수요·거점·거리 항과 출발·종점·중복 지급 규칙을 예시로 확인한다.
6. `road_available`, `demand_observed`, `candidate_eligible_by_policy`, 전체 입력 준비 상태를 구분한다. 후보 정책을 통과했어도 도로자료가 없으면 전체 입력 준비 완료가 아니다.
7. 전체 집합의 모델 입력 준비 상태는 `false`다. 미완료 사실과 추가로 필요한 도로거리·결측 수요 조건을 모델 담당자에게 인계한다.

이 단계에서 설계 기본 방향을 허용한 것은 실제 명세와 산출물을 미리 통과시킨 것이 아니다. 다음 C 검토는 E의 명세에서 산식·분모·결측·그룹·거리·보상 항이 명확히 정의되어 있는지 확인한다.

## C2 / 2026-11-15 / 수요·거점·보상 설계 검토

### 실제 검토 범위와 독립 확인

- 오케스트레이션, C1의 범위 제한, 명세 전체의 모집단·수요·거점·거리·보상·스키마·호환성 규칙과 설정 JSON을 대조했다.
- 설정이 가리키는 7개 원천 경로의 존재를 확인했다. 실제 전체 목록·월별 원천 집계·기준점 자료를 읽어 주요 수치를 독립 재계산했다. 새 전체 도로 그래프가 있다고 가정하지 않았다.
- `112000403`의 학습 월 합계 `23,966 + 27,352 + 27,780 + 25,180 = 104,278`과 `104,278 / 123 = 847.7886178861788`을 확인했다.
- 명세의 구면 반지름 `6,371,008.8m`로 기준점 그룹까지의 최소 haversine 거리와 단일 최근접 배정을 재계산했다. 200/300/500m에서 배정 정류장 `61/103/186`, 배정 그룹 `13/14/14`, 복수 후보 정류장 `0/0/36`을 확인했다. 500m의 애오개·서강대는 후보가 있지만 최종 배정은 없다는 설명도 일치한다.
- 일반 정류장 예시 `0.4 - 0.2×0.5 = 0.3`, 신규 거점 예시 `0.4 + 0.5 - 0.2×0.5 = 0.8`을 확인했다. 실제 노선·학습 결과를 재현한 검증은 아니다.

| 인계 | 기존 train.py가 새 점수를 자동 소비하지 않음을 설명했다. null 포함 행렬과 새 hub_id 규칙을 숫자 전용 기존 로더에 바로 연결하지 않도록 했다. |

설계에 최적 반경·가중치·신규 승객 수를 입증했다는 주장이 없고, 학부 연구 범위에서 재현 가능한 정의와 남는 한계가 명확하다. 제작을 막는 설계 결함은 발견하지 않았다.

### F 제작 및 C3에서 유지할 필수 조건

1. 464개를 보존하고 공통 ID 순서를 검증한다. 필터는 표시·정책 플래그이며 원본 삭제가 아니다.
2. 각 월의 결측 10개와 거리 미확보 129,860개를 null로 유지한다. 전체 준비 상태는 `full_district_model_ready=false`다. `reference_complete=true`는 공식 코드 기준 목록의 완성을 뜻하며 운행·수요·도로 완성을 뜻하지 않는다.
3. 실제 원본에서 수요·M·거점 배정을 재계산한다. 기대 수치를 코드에 결과로 박아 넣는 방식으로 검증을 대신하지 않는다. 정상 0과 null, 제외 정류장, 검증 점수 1 초과를 지도·CSV·JSON에서 구분한다.
4. 지도에서 보상 산술 예시를 제공하면 학습·노선 최적화 결과로 부르지 않는다. 중앙차로 제외 등 후보 정책에 어긋나는 정류장은 산술 참고와 유효한 행동 가능성을 구별해 경고한다. 출발점과 도착점이 같을 때는 재정차 금지와 모순되는 유효 이동을 표시하지 않는다.
5. 300m 밖 거점 후보 없음과 단일 귀속 후 배정 없음, 스냅 품질과 실제 주행 가능성을 각각 구분한다.
6. 원본 거리와 새로운 거리 원천을 혼합하지 않으며 도로선 geometry가 없으면 연결 직선을 실제 도로 경로로 부르지 않는다.
7. 제작 후 재생성·독립 산술·데이터 불변조건·지도 기능과 인계 문서를 확인한다. C2 통과를 최종 산출물 검증으로 대체하지 않는다.

주요 한계는 여전히 수요 원천 기록 부재 10개, 전체 방향별 거리 부족, 기준 목록과 원천의 시점 차이, 실제 보행·정차·회전 가능성 미검증이다. 이를 숨기지 않는 조건에서 지도와 부분 데이터·설계 인계는 유효하다.

### C의 독립 검사 결과

1. **모집단·순서:** 464개 ID의 유일성·사전식 순서와 `stops` 순서가 일치한다. CSV 정류장 순서도 같았다. 42개 중앙차로, 412개 수요 관측 비중앙차로, 259개 도로 보유 진단 집합을 별개로 계산한다.
2. **수요 전수 대조:** 공식 재집계 CSV의 전체 464개×6개월을 통합 JSON과 비교했다. 모든 월간 합계·관측 플래그가 일치하고, 학습 4개월 원천 합계/123일 및 고정 M 점수도 모든 정류장에서 일치했다. master CSV에는 결측 10개, 월별 CSV에는 결측 60행이 빈 수치로 남아 있다. 실제 관측 0명 한 정류장과 혼동하지 않았다.
3. **원본 거리 보존:** 통합 JSON의 거리 행렬과 원본을 재인덱싱한 464개 참조 행렬이 완전히 같았다. 알려진 비용 84,972쌍, 미확보 129,860쌍, 비대각 0m 경고를 보존한다. 대각선 0으로 원천 보유 여부를 판정하지 않는다.
4. **거점:** C2에서 원본 기준점으로 독립 재계산한 61/103/186개 및 중첩 0/0/36개와 산출물이 일치한다. 코드의 그룹 최소 거리, 포함 반경, 그룹·기준점 동률 처리, 단일 귀속이 명세와 같다. 반경 내 후보 없음과 귀속 결과 없음도 별도 지표다.
5. **지도·자료 일치:** 생성 HTML에 내장된 `DATA`를 추출하여 통합 JSON과 비교했고 완전히 같았다. 월간 표시와 상세 원천 값은 공통 ID 인덱스를 사용한다. 지도 표시 점 크기의 상한과 실제 점수의 보존을 구분한다.
6. **보상 산술과 정책:** 지도에서 학습 점수를 사용한다고 표시하며 현재 선택한 표시 월의 수요와 혼용하지 않는다. 출발 거점의 사전 방문과 이미 방문한 도착 그룹, 같은 ID 재정차, 비대각 0m, 수요·거리 미확보, 중앙차로 정책 경고를 구별한다. 이는 단일 이동의 설명용 산술이며 경로 선택·학습 환경을 구현한 것이 아니다.
7. **테스트:** Python의 데이터·도로 의미 검증 16개를 C가 재실행하여 모두 통과했다. DOM 테스트 코드와 기록의 14개 검사를 검토했다. 기록은 464개 표시, 결측·부분집합·중앙차로 필터, 검색·월별 값·검증값 1 초과, 반경 변화, 동일 정류장 금지·0m 경고·미확보 보상·후보 제외 경고·확대/초기화·실행 오류 부재를 확인한다.

### 지도 검증의 경계

지도 기능 검증은 **jsdom 기반의 오프라인 DOM 시뮬레이션**이다. 실제 브라우저 탐색·스크린샷·네트워크·반응형 배치의 시각 품질을 확인한 증거가 아니다. [검증 기록](../evidence/map_validation.json)의 `browser_visual_layout_verified=false`를 유지한다. 이를 브라우저 시각 검수 완료라고 보고하지 않는다.

정적 상단의 14개는 ‘기본 배정 거점 / 반경 300m’로 표시되고, 반경 선택에 따른 103/186개 등의 변화는 별도 동적 설명에 반영된다. 기본값 통계와 현재 표시 조건의 통계가 구분되어 있으므로 현재 문구를 허용한다. 온라인 OSM 배경은 선택 사항이고 실제 도로 경로가 없는 두 위치 연결 직선은 실제 주행선으로 표현하지 않는다.

### 최종 연구 결론과 제한

문헌의 OD·접근성 주장과 프로젝트의 하차 대리 지표·직선 근접성·정책 보상을 구별했다. 임의 반경·가중치를 최적값으로 포장하지 않고 기존 코드와의 비호환을 인계했다. 전체 모델 준비 상태 false와 미관측·미확보를 그대로 유지하므로 학부 연구의 부분 데이터·설계 인계로서 타당하다. 현 산출물에서 수정 없이는 인계할 수 없는 과학적 결함은 발견하지 않았다.

남은 연구 한계는 수요 원천 기록 부재 10개, 전체 지역의 거리 129,860쌍 미확보, 코드 목록·수요·도로의 시점 차이, 실제 출입구·보행·회전·정차 가능성 미검증이다. 292개 또는 259개 결과를 전체 지역 완성으로 바꾸어 표현하면 이 판정의 범위를 벗어난다. 이후 원천이나 설계가 바뀌면 영향을 받는 계산·지도·인계와 연구 결론을 재검토해야 한다.
