2026-11-15. 범위는 역할 4의 연구 근거·보상 명세·선택 구간 도로자료다. 실제 교수 승인이나 성적을 보장하지 않으며 모델 학습·노선 성능 비교를 요구하지 않는다. 현재 최종 조건 판정은 **§8의 통과 범위**를 따른다. 앞부분은 조사 전 질문과 조건을 보존한 기록이며, 문헌 적용·보상 계약·실제 도로 관측 자료의 후속 검토는 §7–8에 있다. 지도 DOM·정적 그림 검증은 별도 근거 파일을 따른다.

## 2. 보상 재검토의 최소 통과 조건

### 2.1. 근거와 출처

1. 실제 읽은 원문 절·페이지와 서지를 명시한다. 논문의 일반 주장을 본 프로젝트의 구체 계수 최적성으로 옮기지 않는다.
2. 서로 다른 논문이 정의하는 수요·OD·서비스·커버리지·운영 목적의 차이를 적는다. 이름만 비슷한 목적을 동일한 지표로 부르지 않는다.
3. 핵심 선택마다 `원문에서 확인한 주장 / 현 데이터의 사실 / 프로젝트 선택 / 미해결 한계`를 분리한다.
4. B의 추천을 C가 원문과 대조한다. 접근하지 못한 전문은 검토했다고 간주하지 않는다.

### 2.2. 권고안의 강도

현 시점의 방어 가능한 선택은 기존 선형식을 **미검증 정책 baseline**으로 보존하고, 원시 다목적 지표를 별도로 인계하는 것이다. 후보 지표는 하차 실적 합, 고유 근접 그룹 수, 거리, 라우터 추정시간, 정차 수, 자료 가용성이다. 이는 아직 Pareto 최적해를 계산했거나 실제 노선을 평가했다는 뜻이 아니다.

가중합의 대안으로 제약식·다목적·커버리지 증가량을 추천할 수 있다. 다만 이들 역시 자료·임계값·선호가 필요하다. 새로운 임의 상수를 넣는 것만으로 기존 약점을 해결했다고 판정하지 않는다. 공간 커버리지와 실제 교통 수요가 다르다는 한계도 유지한다.

### 2.3. 필요한 산술·논리 사례

- 일반 정차·새 그룹·기방문 그룹·출발·종점에 대한 보상 분해
- 가까운 여러 정류장과 한 고점수 정류장의 합산 선호 차이
- 거점 우회 2.5km의 교환비율 및 점수 분포별 영향
- 추가 이동의 보상이 음수일 때 STOP 가능 여부에 따른 허용 경로 차이
- 결측·원본 비대각 0m·필터 변경에 따른 척도·정차 정책의 구별
- 검증 월을 가중치 선택에 썼다면 독립 테스트로 주장하지 않음

이 검사는 목적함수·자료 의미의 성질 검증이며 모델 학습·최적 경로 탐색이 아니다.

## 3. potential-based shaping을 사용할 때의 경계

C는 Ng, Harada, Russell(1999) 원문의 §2의 undiscounted absorbing-state 조건, §3의 Theorem 1 및 Corollary 2를 확인했다. [저자 공개 원문](https://people.eecs.berkeley.edu/~russell/papers/icml99-shaping.pdf).

이 연구는 특정 형태의 보상 변환에서 정책을 보존하는 조건을 다룬다. 새 목적 선호를 합리화하는 보편적 승인 기준은 아니다. 우리 거점 보너스를 원래 하차 목적을 보존하는 학습 가속 항이라고 주장하려면 할인·상태·종료 처리를 포함한 조건을 확인해야 한다.

특히 γ=1에서는 방문 그룹 수의 증가가 potential 차이처럼 표현될 수 있으나, 종료 시 방문 그룹 수에 따라 남는 항이 달라지면 에피소드 총점도 달라진다. 종료 potential/흡수 상태 처리를 생략한 채 정책불변을 주장해서는 안 된다. 반대로 현재 보너스를 의도한 목적의 일부로 명시하는 것은 가능하다. 현재 자료만으로 shaping 기반 개선 효과를 검증했다고 결론 내리지 않는다.

## 4. 실제 도로 경로의 최소 통과 조건

근거: [OSRM 공식 API](https://project-osrm.org/docs/v5.24.0/api/), [공식 데모 사용 정책](https://github.com/Project-OSRM/osrm-backend/wiki/Demo-server). C가 Route·Table·Waypoint·RouteLeg 및 초당 요청 제한·가용성 비보장 부분을 확인했다.

1. **실제 응답:** 경로 geometry를 원천 응답에서 확보한다. 직선을 그린 뒤 도로 기반이라고 하지 않는다.
2. **같은 경로의 비용:** geometry·거리·추정시간은 동일 응답·프로파일·버전으로 연결한다. 기존 292개 비용과 무표시 혼합하지 않는다.
3. **목적과 시간 의미:** OSRM 기본 Route는 주어진 순서의 fastest 경로다. 거리 최소 경로 또는 실제 07–09시 버스 운행시간으로 부르지 않는다.
4. **방향과 스냅:** 경도·위도 순서, from/to ID, 원래·스냅·geometry 끝점을 검사한다. 양방향을 별도로 보존하고 큰 오차·0m 붕괴를 경고한다.
5. **실패 구분:** no_route, no_segment, 서버 취득 실패, 검사 경고를 서로 다른 상태로 남긴다. 부재를 0 또는 검증된 이동 불가로 바꾸지 않는다.
6. **수치 일관성:** 유한·비음수 수치, geometry 길이/API 거리, leg/route 합계를 선언한 허용오차로 대조한다. 차이가 나면 원본을 덮지 않고 검토한다.
7. **제한 준수:** 소규모 대표 구간·직렬·캐시·정책 이하 속도·총량 제한을 지킨다. 429 시 중지하고 다른 접속으로 제한을 우회하지 않는다.
8. **연속성:** 여러 두 점 경로를 연결할 때 중간 정류장의 도착·출발 스냅과 방향 차이를 숨기지 않는다. 개별 최단시간 경로의 단순 합이 실제 연속 운행을 보증하지 않는다.
9. **검사와 주장 구별:** 합성·고정 응답 테스트는 파서와 계산의 의미를 검증하고, 실제 응답 캐시는 실제 취득을 입증한다. 전자만으로 후자를 대신하지 않는다.
10. **모집단 유지:** 대표 구간은 방법 검증 표본이다. 전체 464개 후보를 소규모 실험 집합으로 바꾸거나 전체 비용 준비 완료라고 보고하지 않는다.

car 경로와 품질 검사는 버스 정차·차폭·중량·회전·유턴·사유도로 통행 적합성을 인증하지 않는다. 임의의 confidence 확률을 만들지 않고 관측 가능한 검사항목을 제공한다.

## 7. 내부 질문 트리의 범위 내 결정

다음은 B의 전체 최종 보고서·실제 경로 산출물을 미리 승인하는 것이 아니라, A가 새 인계 계약을 작성하기 위한 설계 판단이다.

1. **연구 목적:** 관측 하차 활동과 근접 그룹의 대리 목적에 한정한다. OD와 운행 자료가 없으므로 실제 수송·환승 편익으로 목표를 확대하지 않는다.
2. **주 지표와 기존 scalar:** 원시 성분 벡터를 주 보고·인계 계약으로 삼고 기존 선형식을 미검증 정책 baseline으로 보존한다. 지금 새 scalar 계수를 반드시 도출하도록 요구하지 않는다. 충분한 선호·실측·비교 근거가 없는데 새 숫자로 바꾸는 것은 개선 증거가 아니기 때문이다.
3. **학습과 연결:** 벡터는 보고·설계 자료이며 DQN이 자동으로 학습하는 새 scalar 보상이 아니다. 모델 담당자가 scalarization 또는 다목적 학습 방법을 명시적으로 선택해야 한다. 우리 범위에서 그 모델을 구현하지 않는다.
4. **종료 계약:** 새 권고안은 optional STOP을 명시할 수 있다. 이때 시작 직후 길이 0의 경로도 허용되면 모든 후속 보상이 음수인 조건에서 그 경로가 최선일 수 있음을 드러낸다. 자료 없이 최소 정차 수를 만들어 넣지 않는다. 비자명한 버스 서비스 성립 조건은 별도 모델·운영 요구이며, STOP 계약만으로 충족했다고 주장하지 않는다. 기존 코드의 maximal extension은 별도 legacy 방식으로 남긴다.
5. **공간 커버리지:** 조건부 증가량 목적은 문헌에 근거한 대안으로 제시할 수 있지만 공간 단위·가중치·접근 조건을 정의해야 한다. 실제 고유 승객 중복 제거 또는 OD 수송량으로 표현하지 않는다.

### 원문 독립 확인

- Benli & Akgün(2023), [저널 원문](https://www.mdpi.com/2227-7390/11/21/4488), §3의 승객·운영 목적 및 §4.1의 식(24)를 확인했다. 서로 다른 목적을 분리하고 한 목적을 제약으로 옮겨 대안을 비교하는 접근은 확인된다. 우리 데이터로 그 논문의 승객·차량 목적이나 Pareto 최적해를 계산했다는 뜻은 아니다.
- Chekuri & Pál(2005), [저자 공개 원문](https://chekuri.cs.illinois.edu/papers/orienteering.pdf), PDF 2쪽의 방향 그래프·예산·집합 함수 정의와 §2의 조건부 증가량 정의를 확인했다. 단순 방문 점수와 중복을 고려하는 집합 목적의 구별에 적용할 수 있다. 해당 알고리즘의 근사 보장을 불완전한 현재 도로·수요 자료에 옮기거나 교통 계수를 차용할 근거는 아니다.

이 결정은 목적과 근거의 일치를 강화한다. 실제 교수 평가 통과, 모델 성능 개선 또는 새 계수의 검증 완료를 주장하지 않는다.

이번 후속 검토는 기존 C의 원문·실제 응답 검토를 재개하여 남은 두 조건을 확인한 것이다. 신규 문헌 원문 전체나 기존 C의 모든 검사를 이 후속 검토자가 다시 수행했다고 주장하지 않는다. 기존 C는 Ng 등의 종료 조건, Benli·Akgün의 다목적 설계, Chekuri·Pál의 집합 가치와 실제 도로 응답 24개의 원문 대조를 확인했으며, 최종 표기와 공집합 정의를 수정 조건으로 남겼다.

### 독립적으로 다시 확인한 내용

1. [보상 계약 v2](../../data/reward_contract_v2.json)는 원시 성분을 주 보고 단위로 두고 기존 선형식을 `uncalibrated_policy_baseline`으로 분리한다. 가중치의 32개 중앙값 정류장·2.5km 교환비율과 검증 부재를 숨기지 않는다. 벡터를 DQN의 새 스칼라 보상이나 계산된 Pareto 최적해로 표현하지 않는다.
2. 공간 집합 대안은 `F(S)=Σ_z w_z max({0}∪{a_zi:i∈S})`, `F(∅)=0`, 비음수 가중치·접근값으로 경계를 정의했다. [B 보고서](REWARD_EVIDENCE_REVIEW.md)와 기계 판독 계약에서 같은 조건을 확인했다. 이 대안은 채택·실측된 고유 승객 지표가 아니다.
3. optional STOP은 시작 직후 빈 경로 허용 및 모든 후속 수익이 음수일 때 빈 경로가 이길 수 있음을 명시한다. 최소 서비스 제약은 미식별로 남기고 실제 비자명한 버스 서비스 성립 전에 추가 요구가 필요하다고 설명한다. 따라서 최소 정차 수를 근거 없이 만들어 넣지 않은 현재 계약은 축소된 수학적 대리 문제의 인계로 허용한다. 기존 모델의 강제 연장 계약은 바꾸지 않았다.
4. [경로 GeoJSON](../../data/routes/v1/routes.geojson) 24개와 [CSV](../../data/routes/v1/route_metrics.csv) 24행, [manifest](../../data/routes/v1/manifest.json)의 파생 목적은 `car_profile_routing_weight_not_distance_minimum`으로 수정됐다. 실제 `route_weight_name=routability`, `minimum_duration_verified=false`, `shortest_distance_verified=false`와 버스 검증 false를 보존한다.
5. 24개 Feature의 geometry·거리·추정시간을 원문 응답과 직접 대조했고 모두 동일했다. 각 원문 응답 바이트의 SHA-256도 Feature의 해시와 모두 일치했다. 기존 행렬을 덮거나 다른 원천 비용을 새 경로와 같은 값으로 처리하지 않는다.
6. [취득 방법](SELECTED_ROUTES_METHOD.md)은 원문 가중치와 추정시간이 다른 1개 사례, 데이터 버전 미제공, 자동차 시간과 출근시간 버스 실측의 차이를 설명한다. API 일반 설명을 실제 프로파일의 순수 시간 최소 보장으로 확대하지 않는다.

### 통과 범위와 남는 조건

이 판정은 **문헌 근거의 제한을 반영한 보상 인계 계약과 소규모 실제 도로 관측 자료**에 한정한다. 계수의 적정성, 실제 교수의 평가, 전체 464개 이동 비용의 완성, 버스 운행 가능성, 모델 성능을 통과시킨 것이 아니다. `full_district_model_ready=false`를 유지한다.

지도 소스에 연결한 실제 도로선의 DOM 검사와 정적 그림 확인은 A·F의 최종 산출물 검사로 별도 기록해야 한다. 이 후속 검토자가 브라우저 화면 배치·새 지도 테스트를 수행했다고 주장하지 않는다. 지도에서는 실제 응답 geometry만 실선으로, 경로 미확보 관계는 도로선과 구별하고 비용 원천을 표시해야 한다.
