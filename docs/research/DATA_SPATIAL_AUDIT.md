# 정류장 모집단·도로거리·거점 공간 검증

분석일: 2026-11-15. 연구 범위는 정류장 맵·수요·거리·거점·보상 입력이며 모델 학습·노선 성능 실험은 수행하지 않았다.

## 1. 핵심 연구 결과

**기존 282개 정류장은 서대문구 전체 목록이 아니다.** 2026-09-02 서울시 공식 정류소 위치정보에서 ARS 구역 코드 `13`인 정류소는 464개다. 기존 입력 282개는 이 중 60.78%이며 182개가 빠져 있다. 원본 연구 지역 808개를 다시 확인해도 이 공식 목록과 겹치는 것은 292개뿐이다.

이는 단순한 후보 수 확대 문제가 아니다. 정류장 전체를 지도에 표시할 수 있는 좌표 목록과, 수요·도로거리가 모두 연결되어 모델에 전달 가능한 목록을 분리해야 한다. 누락 정류장에 수요 0명이나 도로거리 0m를 채워서는 안 된다.

분석 수치 정본: [spatial_audit.json](../evidence/spatial_audit.json).

## 2. 공식 모집단 기준과 검증 방법

### 사용한 공식 자료

| 자료 | 기준 시점·실제 사용 범위 | 용도 |
| --- | --- | --- |
| [서울시 버스정류소 위치정보 OA-15067](https://data.seoul.go.kr/dataList/OA-15067/S/1/datasetView.do) | 2026-09-02 XLSX, 서울 전체 11,236행 | ID·ARS·좌표·정류소 유형 기준 목록 |
| [서울시 시내버스 정류소 현황 OA-22187](https://data.seoul.go.kr/dataList/OA-22187/F/1/datasetView.do) | 2026-09-30 XLSX, ARS 구역 코드와 자치구 대조 | `13`→서대문구 코드 의미 검증 |
| [국가철도공단 철도 데이터 포털: 전체 기관 역사정보](https://data.kric.go.kr/rips/M_01_01/detail.do?id=32) | 전체_도시철도역사정보_20260630 XLSX, 1,099행 중 근접 역사 좌표 | 역·노선 식별, 공신력 있는 거점 좌표 |

실제 읽은 범위는 파일의 표와 메타데이터다. 행정구역 경계 폴리곤을 이용한 모든 점의 포함 검사를 했다는 뜻은 아니다. OA-22187의 210개 서대문구 시내버스 정류소 집계는 마을버스까지 포함하는 OA-15067의 464개와 범위가 다르므로 서로 같은 총계로 취급하지 않았다.

### 선택 기준

- 공식 위치 파일의 `ARS_ID`를 5자리 문자열로 유지하고 앞 두 자리가 `13`인 행을 선택했다.
- 공식 시내버스 파일에서 `13-`이 서대문구에 대응함을 확인했다. 시내버스 표의 ARS `13` 행에 다른 자치구명이 붙은 사례는 없었다.
- 이 기준은 **공식 ARS 구역 코드 기반 목록**이다. 정류장 좌표의 행정경계 포함이나 모든 서비스의 실시간 운영 상태까지 보장하지 않는다.
- 공식 ARS `13` 목록 464개 중 `NODE_ID`가 `112`로 시작하는 것은 449개다. 나머지 15개는 다른 NODE 접두어이며, 이 차이 때문에 기존 `112` 필터로 행정 구역 목록을 대체할 수 없다.

반례: 신촌오거리·2호선신촌역 `113000417`, 이대역 `113000411`, 가좌역3번출구 `113000532`는 공식 ARS 구역은 `13`이지만 NODE 접두어는 `112`가 아니다.

인계할 전체 기준 목록: [seodaemun_bus_stops_official.csv](../../data/reference/seodaemun_bus_stops_official.csv). 원본 컬럼의 의미와 출처, 기준일, 기존 808개·282개 포함 플래그를 함께 보존했다.

## 3. 수집 범위 차이

| 비교 | 정류장 수 | 공식 ARS13 464개 대비 |
| --- | ---: | ---: |
| 공식 위치 목록 | 464 | 100% |
| NODE112만 사용한 공식 목록 | 449 | 96.77% |
| 기존 모델 입력 | 282 | 60.78% |
| 원본 808개와 공식 목록의 교집합 | 292 | 62.93% |
| 원본 808개에도 없는 공식 정류장 | 172 | 37.07% |

기존 연구 지역의 최대 위도는 약 37.58193이지만 공식 ARS13 목록은 약 37.60568까지 있다. 홍제역·서대문세무서 주변을 포함한 북쪽 정류장이 기존 자료에 빠져 있다. 경도·위도 범위만으로 모든 누락 원인을 단정하지는 않으나 ‘기존 데이터가 이미 전체’라는 주장은 기각할 수 있다.

전체 목록에서 원본에 없는 172개: [seodaemun_missing_from_original808.csv](../../data/reference/seodaemun_missing_from_original808.csv). 이는 ‘원본 808개 기준’의 차집합이며 아래 공식 월별 수요 재확보 후에도 원본과의 차이를 설명하는 자료로 유지한다.

### 공식 월별 수요 재확보 반영

[OA-12913 월별 원본](https://data.seoul.go.kr/dataList/OA-12913/S/1/datasetView.do)을 2026년 5–10월 정류장 표준 ID별로 재집계한 [후속 수요 자료](../../data/reference/seodaemun_ridership_202605_202610.csv)에서는 공식 464개 중 매월 454개에 관측값이 있다. 같은 10개는 6개월 모두 원자료 행이 없으며, 수요 0이 아니라 결측으로 보존했다. 수집·집계 근거와 원본 해시는 [ridership_provenance.json](../../data/reference/ridership_provenance.json)에 있다.

미관측 ID는 `101000248`, `112000170`, `112000372`–`112000377`, `112000440`, `113000532`다. 따라서 현 시점에서 전체 확대의 수요 결측은 원본 차집합 172개가 아니라 10개이며, 도로거리 커버리지 문제는 별도로 남는다. 기존 정류장 292개와 겹치는 월별 집계는 팀 전처리 값과 모두 일치한다.

## 4. 정차 후보 정책

| 후보 집합 | 전체 유지 | 중앙차로 제외라는 기존 연구 가정 적용 |
| --- | ---: | ---: |
| 기존 NODE112 입력 | 282 | 259 |
| 공식 ARS13과 원본 교집합 | 292 | 259 |
| 공식 ARS13 전체 | 464 | 422 |

공식 전체 유형은 마을버스 243, 일반차로 173, 중앙차로 42, 가로변전일 4, 가로변시간 2개다. 원본 교집합 292개는 중앙차로 33개이므로 비중앙차로 259개다. 기존 282개에서 빠진 교집합 정류장 10개는 전부 중앙차로다.

**제안:** 전체 정류장 지도에는 464개 모두 표시하고 중앙차로 표시를 필터로 제공한다. 수집 모집단을 정차 정책 때문에 숨기지 않는다. 모델 입력에는 `candidate_eligible`과 정책명을 별도 제공하여 전체 목록과 후보 가정을 구별한다. 중앙차로 제외는 제공자의 연구 가정이며, 실제 법적 마을버스 정차 금지 여부를 이 자료만으로 판정하지 않는다.

## 5. 도로거리 커버리지와 품질

두 원본 도로 ZIP의 CSV 652,056행을 읽어 공식 목록과 겹치는 292개 ID의 방향별 거리를 검사했다.

- 292개 내부의 모든 비대각 방향별 거리 84,972개가 존재한다. 중복·음수·비유한값은 없었다.
- 공식 464개에 필요한 비대각 방향별 거리는 214,832개다. 원본만 사용하면 129,860개가 없다.
- 따라서 기존 원본은 전체 정류장 확대의 거리 입력으로 충분하지 않다. 결측을 직선거리로 대체하면 도로거리와 동일한 비용이라는 거짓 가정을 넣게 된다.
- 292개 스냅 품질은 `ok` 267, `check` 20, `unverified` 5개다. `ok`라도 차량 회전·유턴·아파트 내부 도로 통행까지 검증한 것은 아니다.

### 서로 다른 정류장 사이의 0m

`112900003 → 112900157`은 도로거리 0m, 원본 직선거리 24.4m다. 출발점은 한 도로 구간 끝에, 도착점은 다음 구간 시작에 스냅되어 노드 `2451941009`를 공유한다. 이는 스냅 근사의 영향으로 설명되지만 실제 정차 위치 이동비용이 0이라는 증거는 아니다.

**제안:** `road_m_raw=0`, 품질 플래그, 좌표 직선거리 하한을 별도 보존한다. 운영 가능한 대체 도로 경로가 검증되기 전에는 실제 도로거리로 보정했다고 표현하지 않는다. 최소 거리 하한을 정책적으로 적용할 경우 원본과 별도 열·보정 사유로 표시하고 C의 검토를 거친다. 누락된 129,860개를 0이나 직선거리로 조용히 채우지 않는다.

## 6. 도시철도·연대앞 거점의 공간 근거

공식 KRIC 파일에서 위도·경도가 있는 역사 기준점을 읽고 공식 버스 정류소 중 하나와 직선거리 500m 이내인 역을 후보로 추렸다. **500m는 누락 방지를 위한 초기 공간 스크리닝 범위이며 보상 거점의 확정 반경이나 문헌상 최적값이 아니다.** 최종 매핑 반경과 단일/복수 귀속은 E·C가 근거와 목적을 검토하여 결정한다.

후보 목록은 [hub_anchors_official.csv](../../data/reference/hub_anchors_official.csv)에 있다. 19개 철도 역사 기준점과 연대앞 버스 기준점 3개, 총 22개 기준점을 16개 그룹으로 정리했다. 개별 행의 원본 역번호·노선·좌표·주소·기준일·출처를 제공한다.

| 거점 그룹 | 좌표 근거·구분 원칙 |
| --- | --- |
| 홍제·무악재·독립문·서대문 | 공식 역사 기준점. 북쪽 정류장 확대 시 홍제 누락을 방지 |
| 신촌(2호선)·신촌(경의중앙선) | 이름이 비슷하지만 서로 다른 역이므로 별도 그룹 |
| 이대·아현·가좌·증산·서강대·애오개 | 공식 역 좌표와 실제 정류장 거리로 후보 판단 |
| 충정로 | 2·5호선 기준점을 같은 역 그룹으로 묶음 |
| 홍대입구·디지털미디어시티 | 호선별 기준점은 유지하되 동일 역은 한 그룹. 행정구 밖 역사라도 구내 버스 정류장에서 접근 가능하면 경계 인접 거점 후보 |
| 연대앞 | 공식 버스 정류장 `112000031`, `112000032`, `112900188` 좌표를 버스 접근 기준점으로 사용한 프로젝트 그룹 |

KRIC 좌표는 역사 기준점이며 출입구 좌표가 아니다. 직선거리에는 횡단보도·담장·계단·경사·실제 보행시간이 반영되지 않는다. 연대앞 기준점도 캠퍼스 정문 측량점으로 주장하지 않는다. 따라서 거점 태그는 잠재적 접근성의 근사이지 실제 환승·보행 가능성 인증이 아니다.

## 7. 설계 및 제작 단계에 전달할 판단

1. 전체 지도 모집단은 2026-09-02 공식 ARS13 464개로 잡고, 기준일·코드 기반 선정이라는 한계를 함께 적는다.
2. 측정 자료가 있는 부분집합을 전체와 분리한다. 일부 정류장 데이터 미확보는 낮은 수요라는 뜻이 아니다.
3. 중앙차로 포함 여부는 별도 후보 정책이며 전체 위치 목록의 완전성과 혼동하지 않는다.
4. 거점 매핑은 이름 검색 대신 공식 좌표와 그룹 ID를 사용한다. 반경은 프로젝트 선택임을 밝힌다.
5. 현 거리 자료의 완전성은 292개에 한정된다. 전체 입력 준비가 되기 전에 기존 코드가 바로 전체 실험을 할 수 있다고 표현하지 않는다.
6. 실제 회전·유턴·보행·정차 검증은 제공 자료의 범위를 넘는다. 지도와 모델 인계서에 남는 한계로 명시한다.

이 결론은 조사 결과와 보수적 설계 제안이며 C의 단계 검토를 대체하지 않는다.

## 8. 재현 방법과 자료 식별

[spatial_sources.json](../../data/reference/spatial_sources.json)에 공식 원문·파일 URL, 기준일, SHA-256, 선택 기준을 기록했다. 공식 XLSX 스냅샷과 기존 첨부를 읽는 다음 명령은 위치 기준 목록·거점 후보·공간 감사 JSON을 재생성하며 기존 모델 입력을 수정하지 않는다.

```powershell
python scripts/audit_role4.py
```

이 스크립트는 원본 월별 수요 재집계나 새 도로망 계산을 수행하지 않는다. 수요 자료의 재현은 해당 provenance의 절차를 따르며, 도로거리 입력의 원본 커버리지와 후속 복구는 구별한다.
