# 보상체계 재검토: 원문 근거와 채택 가능한 결정

2026-11-15. B의 문헌 검토와 설계 권고다. 모델 구현·학습·노선 탐색 성능 실험은 하지 않았다. C의 독립 판정은 별도다. 연구 근거, 현재 자료의 사실, 프로젝트의 선택을 구별한다.

## 1. 결론

현재 `d_j + 0.5×신규 거점 − 0.2×거리(km)`는 **명시적인 선호를 가진 활동 점수 수집용 기본안**으로 보존할 수 있다. 그러나 문헌은 이 계수가 서울에서 적정하다는 근거를 제공하지 않는다. 다른 임의 숫자로 바꾸는 것도 개선의 증거가 아니다.

권고는 새 ‘검증된 최적 보상’을 만들어 내는 대신 **원시 목적 벡터를 기본 보고 단위로 삼고, 기존 단일 점수는 미검증 정책 기본안으로 분리**하는 것이다. 가중치의 의미·종료 계약·대리 지표의 범위를 명세한다. 고유 공간 커버리지나 정보의 한계효용을 쓰려면 별도 정의를 갖춘 대안으로 취급한다.

## 2. 실제 확인한 원문 5개

### E1. Ng, Harada & Russell (1999): 목적 변경과 학습 보조를 구분

*Policy Invariance Under Reward Transformations: Theory and Application to Reward Shaping*, ICML, pp. 278–287. [저자 원문](https://people.eecs.berkeley.edu/~russell/papers/icml99-shaping.pdf). PDF p.3의 episodic/absorbing-state 가정, pp.4–5의 §3 Theorem 1·Corollary 2와 증명을 확인했다. 문자 추출이 깨진 대학 공개본은 같은 논문의 페이지 그림으로도 읽었다.

원문은 추가 보상이 원래 최적 정책을 보존하는 조건을 다룬다. 주어진 정규성·종료 가정 아래 potential difference 형태가 핵심이다. 이것은 교통 목적이나 계수를 선택해 주는 논문이 아니다.

우리의 거점 보너스는 새로운 거점 방문을 더 가치 있게 하려는 **목적의 일부**로 부르는 것이 정확하다. ‘학습만 빠르게 하고 목적은 그대로인 보조 보상’이라고 주장하지 않는다. 아래의 종료 potential 조건을 생략하면 정리를 잘못 적용하게 된다.

### E2. Chekuri & Pál (2005): 방문점 합산 외에 집합 가치도 가능

*A Recursive Greedy Algorithm for Walks in Directed Graphs*, FOCS, pp.245–253, DOI [10.1109/SFCS.2005.9](https://doi.org/10.1109/SFCS.2005.9). [저자 PDF](https://chekuri.cs.illinois.edu/papers/orienteering.pdf), [저자 서지](https://chekuri.cs.illinois.edu/pub.html). PDF pp.1–2의 문제 정의와 submodularity, p.3의 적용 범위를 확인했다. 알고리즘·근사비 증명 전부를 재현하지 않았다.

방향 있는 비용 그래프에서 예산 내 s–t walk가 방문한 집합의 가치를 높이는 문제를 정의한다. 점별 최초 방문 이익 외에 monotone submodular set function을 허용한다.

적용 가능한 것은 **한계이득·방문 집합에 따라 달라지는 가치라는 구조**다. 특정 버스 수요 예측식·반경·가중치의 근거는 아니다. 논문의 근사 보장은 우리 보상이나 학습 모델에 자동으로 적용되지 않는다.

### E3. Benli & Akgün (2023): 승객과 운영자 목적을 분리

*A Multi-Objective Mathematical Programming Model for Transit Network Design and Frequency Setting Problem*, Mathematics 11(21), 4488. [공식 전문](https://www.mdpi.com/2227-7390/11/21/4488), DOI [10.3390/math11214488](https://doi.org/10.3390/math11214488). §3.1, §3.2의 Eq.(1)–(6) 및 정차 수 제약, §4의 ε-constraint Eq.(24)를 확인했다. 보고된 최적화 실험을 실행·재현하지 않았다.

OD·빈도·용량을 가진 모델에서 승객의 이동·대기·환승과 운영자의 차량 규모를 구별한다. 운영자 목적을 제약으로 옮겨 서로 다른 수준의 해를 비교한다.

우리에게는 그 입력이 없으므로 계산값을 이식할 수 없다. 차용할 원칙은 **상충하는 목적과 제약을 드러내고, 단일 점수만으로 우열을 숨기지 않는 것**이다. 이 논문은 우리의 0.5·0.2를 뒷받침하지 않는다.

### E4. Holliday, El-Geneidy & Dudek (2025): 스케일링과 trade-off도 설계 선택

*Learning Heuristics for Transit Network Design and Improvement with Deep Reinforcement Learning*. [arXiv v6 전문](https://arxiv.org/html/2404.05894v6), DOI [10.1080/21680566.2025.2561863](https://doi.org/10.1080/21680566.2025.2561863). 이번 재검토에서는 §3의 Eq.(4)–(11), 경로 제약과 비용 스케일 정의를 직접 다시 확인했다.

승객 비용은 OD 가중 통행시간이고 운영 비용은 경로 운행시간이다. 단일 비용으로 합칠 때 스케일과 trade-off를 별개로 둔다. 제약 위반 패널티의 상대적 크기가 작아질 수 있다는 문제도 명시한다.

따라서 정규화한 항끼리도 실제 분포와 교환비율을 확인해야 한다. 이 논문의 대칭 비용·OD와 우리의 방향별 거리·하차 활동은 다르므로 원문 계수나 승객 편익 해석을 그대로 복사하지 않는다.

### E5. Transport for London (2015): 근접 접근과 실제 이동 편익은 다르다

*Assessing transport connectivity in London*. [공식 전문](https://content.tfl.gov.uk/connectivity-assessment-guide.pdf). 인쇄 pp.6–7의 PTAL 의미·한계, pp.18–19 Table 2.1의 보행·대기·동일 서비스 처리, p.40의 복수 지표 해석 권고를 확인했다. PDF 위치와 인쇄 페이지를 혼동하지 않았다.

접근성 지표에 보행 경로와 서비스 빈도·대기 요소가 들어가고, 같은 서비스의 가까운 정류장을 반복 가산하지 않도록 단순화한다. 동시에 목적지 도달성·환승 용이성·혼잡을 모두 표현하지는 못한다고 밝힌다.

이는 직선 근접성을 실제 환승 편익으로 부르지 말아야 한다는 근거다. 우리 거점 그룹은 PTAL이 아니며, 원문의 수치 반경·0.5 가중치를 서울 거점 보너스와 동일시해서는 안 된다.

## 4. 추천하는 보고·소비 계약

### 4.1. 기본 보고는 구성요소 벡터

```text
V(R) = (
  historical_alight_activity,   # 경유지의 과거 하차 일평균 합
  normalized_activity_sum,
  distinct_hub_groups,
  distance_m,
  router_estimated_duration_s,  # 있을 때만; 버스 실측시간 아님
  stop_count,
  demand_and_road_coverage,
  quality_flags
)
```

벡터를 보존한다고 Pareto 최적성을 입증한 것은 아니다. 우리 범위에서는 각 항을 숨기지 않는 인계·보고 규칙이다. 기존 스칼라 점수도 구성항과 함께 제공할 수 있으나 `legacy_baseline` 또는 `uncalibrated_policy_scalar`로 표시한다. 서로 다른 계수로 계산한 총점끼리 같은 척도의 성능처럼 비교하지 않는다.

학습에 단일 수치가 필요한 모델 담당자는 자신의 목적과 제약을 명시한 뒤 가중치를 선택해야 한다. 현재 자료만으로 그 선택을 통계적으로 추정했다고 주장할 수 없다. 한계를 밝히는 것이 의무를 회피하는 것은 아니며, 새 임의 계수를 ‘논문 기반 최적 보상’으로 포장하는 것보다 타당하다.

### 4.2. 공간 커버리지 대안은 별도 목적

이론적으로 비음수 고정 가중치 w_z와 접근 정도 a_zi를 정한 다음 다음과 같은 집합 가치를 정의할 수 있다.

```text
F(S) = Σ_z w_z * max({0} ∪ {a_zi : i∈S})
F(∅) = 0  # w_z ≥ 0, a_zi ≥ 0
incremental_reward = F(S ∪ {j}) - F(S)
```

이는 E2의 허용 함수 범위에서 영감을 얻은 **우리의 수학적 대안**이지 논문의 버스 실험식을 복사한 것이 아니다. max의 증가분은 이미 커버한 집합이 커질수록 줄어들므로 nonnegative weighted max는 monotone submodular다. 하나의 공간 단위 z가 여러 정류장에서 접근 가능해도 max로 한 번만 반영된다.

단, z가 격자인지, 생활권인지, 원천 정류장인지, w_z가 인구인지 하차 활동인지, a_zi가 도보 경로인지 직선 반경인지부터 정해야 한다. 좌표와 하차량만으로 고유 승객·신규 수요가 되는 것은 아니다. 현재 활동 합산을 이 식으로 바꾸면 목표가 달라진다. 검증되지 않은 커버리지 자료를 추가해 현재 기본안을 자동 교체하지 않는다.

### 4.3. 종료 계약은 명시적이어야 한다

`free_terminal`은 종점 ID가 고정되지 않았다는 뜻일 뿐, 자발적 STOP이 있다는 뜻은 아니다. 현재처럼 더 이동할 수 없을 때 끝나는 계약을 쓰면 이를 그대로 명명한다. 최적 종료까지 선택하는 계약을 원하면 STOP의 가능 시점·추가 보상·최소 서비스 조건을 별도 명세해야 한다.

STOP의 기본 종료 추가보상은 0으로 제안할 수 있지만, 시작 직후 빈 경로까지 허용할지는 별개다. 최소 정차나 필수 종점·서비스 조건은 목적에 따라 정하고 원문의 정차 개수를 서울의 최적값으로 복사하지 않는다. 이 계약 정의는 모델 담당자 인계이며 본 작업에서 학습 환경을 구현하지 않는다.

## 5. potential shaping의 정확한 적용 경계

γ=1이고 상태에 방문 거점 집합 H가 있을 때 비종료 전이의 최초 그룹 보너스는 `Φ(H)=β|H|`의 차분으로 쓸 수 있다. 따라서 ‘거점 보너스는 potential 형태가 전혀 아니다’라는 비판도 부정확하다.

하지만 현재 유한 경로에서 그 합은 `β(|H_final|-|H_start|)`다. 종점의 potential이 경로마다 달라지면 이 항은 경로의 순위를 바꾼다. E1의 absorbing terminal과 terminal potential 조건을 만족시키는 별도 처리가 없는 상태에서 최적 정책 보존을 주장할 수 없다. 필요한 종료 보정을 넣으면 원래 거점 선호로 얻고 싶었던 최종 차이가 상쇄될 수도 있다.

새 거점 선호가 실제 목적이면 목적 항으로 선언하면 된다. 이를 학습 가속만을 위한 보조 항으로 설명하지 않는 것이 핵심이며, 모든 보상 설계가 policy-invariant여야 한다는 요구가 아니다.

## 6. 현재 자료에서 확인된 문제와 최소 검증

[보상 분포 계산](../evidence/reward_tradeoff_audit.json)에서 비중앙차로·수요 관측 412개의 중앙값은 0.015588이다. 보너스 0.5는 약 32.08개분, 거리비용 2.5km분이다. 중앙값 수요의 손익분기 추가거리는 약 77.94m다. 이는 산술적 해석이며 학습 결과가 아니다.

밀집 정류장 5개×0.2와 단일 정류장 0.7은 같은 1km 비용 아래 각각 0.8과 0.5다. 현재 목적에는 맞지만 고유 접근권 개선을 입증하지 않는다. 점수 0.01, 거리 500m의 후속 이동은 -0.09인데 STOP이 없으면 계속해야 한다. 두 사례는 목적과 허용 경로의 의미를 설명하는 반례이지 특정 알고리즘의 실패 실험은 아니다.

최소 성질 검사는 다음으로 한정한다.

- 현재 기본안: 같은 그룹 반복 보너스 0, 최초 방문 항 정확성, 수요/거리 null이면 정의 불가, 0과 null 구별
- 집합 대안: 동일 커버리지의 반복 추가 이득 0, 집합 포함에 따른 한계이득 감소, 시작 집합을 뺀 증가분의 telescoping
- 종료: 자발적 STOP과 강제 종료가 다른 계약임을 보여 주는 음수 후속 이동 사례
- 단위·교환비율: 원시 수요·그룹 수·거리·시간을 총점과 함께 보존; 다른 계수 점수를 직접 성능 비교하지 않음

모델 학습·알고리즘 성능·계수 최적성은 이 검사로 입증하지 않는다. 관련 비교는 모델 담당자의 후속 범위다.

## 7. 무엇을 채택하고 무엇을 기각하는가

**채택 권고:** 원시 벡터 우선, 기존 스칼라의 미보정 기본안 표시, 정확한 하차 proxy 명칭, 최초 그룹 선호 항의 목적 변경 인정, 종료 계약 명시, 별도 공간 커버리지 대안의 정의·한계, 산술 성질 검사.

**기각:** 논문에서 0.5·0.2의 적정성을 차용했다는 주장, 일부 항을 0–1로 만들었으니 균형이라는 주장, 자동차 예상시간을 버스 시간으로 사용, straight-line 거점을 환승 편익으로 사용, 집합 커버리지 proxy를 실제 승객 중복 제거로 사용, Ng 정리의 terminal 조건 생략, 단순 대안으로 우리 학습 모델의 근사 최적성 보장 주장.

원문 기록과 실제 읽은 범위는 [reward_evidence_sources.json](reward_evidence_sources.json)에 있다. 유료 자료나 확인하지 못한 전문을 채택 근거로 삼지 않았다. 논문 전문 재배포와 실제 교수 평가 통과 보장은 하지 않는다.
